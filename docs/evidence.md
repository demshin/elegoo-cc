# Основания пробных статей

Дата разбора: **01.11.2026**. Здесь только обезличенные пересказы. Имена, контакты, исходные реплики и вложения не перенесены.

Каждый код обозначает один эпизод одного владельца. Независимость выбранных авторов проверена по признакам автора в экспорте; повторные сообщения объединены. Это не даёт статистики по всему сообществу и не исключает существования нескольких аккаунтов у одного человека.

Локальные ссылки требуют исходной выгрузки в `data/`. Дата — дата сообщения, без пересчёта часового пояса экспорта. Цитаты и фото при необходимости смотрятся только в локальном оригинале.
