# CC1: как вынуть PTFE-трубку из головы

В штатной голове CC1 трубку держит фитинг с нажимным фиксатором. Удерживайте фиксатор нажатым, пока вытаскиваете трубку. Если тянуть её без нажатия, соединение не освобождается.

**Область:** оригинальный Centauri Carbon со штатным входом под одну трубку, без хаба CANVAS. Для хаба 4-в-1 процедура другая. **Обновлено:** 05.11.2026.

## Для новичков

1. **Штатно выгрузите филамент.** В [инструкции ELEGOO по замене трубки](https://wiki.elegoo.com/en/Centauri-carbon/how-to-replace-the-PTFE-tube) это **Function → Extruder → Unload**. Дождитесь завершения выгрузки. Если пруток застрял, не вытягивайте его вместе с трубкой силой: сначала разберитесь с [засором или застреванием](../printing/nozzle-clog.md).
2. **Остановите и остудите принтер, выключите питание и выньте сетевой кабель.** Перед работой с механизмом головы отключение питания предусмотрено и в [руководстве ELEGOO по экструдеру](https://wiki.elegoo.com/en/Centauri-carbon/how-to-replace-the-gear-of-the-extruder).
3. **Нажмите фиксатор вокруг трубки вниз, к фитингу.** В инструкции производитель использует пинцет. Нажимать нужно на фиксатор, а не гнуть весь штуцер.
4. **Удерживая нажатие, вытяните трубку из фитинга без перекоса.** Если она не освобождается, остановитесь и проверьте, полностью ли нажат фиксатор. Усиливать рывки не нужно.

## Для опытных

Это снятие одной трубки, а не разборка экструдера. Для полной замены с прокладкой через кабельную цепь используйте руководство ELEGOO целиком. При обратной установке проверьте соединение и отсутствие заломов; производитель отдельно указывает этот контроль после замены.

После установки CANVAS на CC1 штатного одиночного входа уже нет. Не переносите на хаб эту инструкцию по одному кольцу: сверяйте руководство установленного комплекта. Для CC2 Combo отдельно разобрано [снятие трубок с хаба 4-в-1](cc2-ptfe-release.md).

## Проверка результата

Трубка извлечена, фитинг не повреждён. Если ставите её обратно, убедитесь, что соединение удерживается, трубка не перегнута, а филамент штатно загружается. Снятая трубка сама по себе не подтверждает устранение засора.
