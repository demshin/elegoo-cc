# CC1 доступен дома, но не из другой сети: доступ через VPN

Если приложение или слайсер видят CC1 по домашнему Wi-Fi, а через мобильный интернет или с работы связь пропадает, одного локального подключения недостаточно. Несколько владельцев независимо задавали этот вопрос. Один из них настроил SSTP VPN на Keenetic и подтвердил открытие интерфейса, отправку файла и завершённую печать из другой сети. Он рассказал об этом повторно; второго успешного испытания это не добавляет. [REMOTE-01–REMOTE-03](../../docs/evidence-history.md#remote).

**Область:** исходный Centauri Carbon с работающим локальным веб-интерфейсом; подтверждённый случай — Keenetic и удалённый компьютер, октябрь 2025 года. Точная модель роутера, ОС компьютера и версии ПО не названы. На телефоне этот владелец ещё просил помочь с подключением. **Проверено по источникам:** 01.11.2026.

## Для новичков

Локальный IP на экране принтера — адрес внутри домашней сети. VPN к домашнему роутеру создаёт путь в эту сеть. Обычное VPN-приложение, которое выводит в интернет через чужой сервер, само по себе не даёт доступа к домашней сети.

1. Дома откройте IP принтера в браузере и убедитесь, что видео, состояние и отправка задания работают. Запишите этот адрес; удобно закрепить его за принтером в настройках домашнего роутера.
2. Настройте VPN-сервер на домашнем роутере и разрешите VPN-пользователю доступ к сегменту, где находится принтер. Для подтверждённого варианта используйте [официальную инструкцию SSTP Keenetic](https://support.keenetic.ua/start/kn-1112/en/19090-sstp-vpn-server.html): нужны компонент сервера, имя KeenDNS с доверенным сертификатом и учётная запись с нужным доступом.
3. На удалённом компьютере создайте подключение **к этому серверу**. В инструкции [Keenetic для Windows](https://support.keenetic.ua/start/kn-1112/en/21666-connecting-to-an-sstp-vpn-server-from-windows.html) указаны тип SSTP, имя KeenDNS и данные VPN-пользователя. Для другой ОС выберите её руководство.
4. Подключитесь из другой сети к домашнему VPN. Сначала откройте в браузере прежний локальный IP принтера.
5. В слайсере используйте профиль CC1, подходящий тип подключения ElegooLink и тот же IP. В подтверждённом случае менять адрес принтера на внешний адрес роутера не потребовалось.
6. Проверьте просмотр состояния и передачу небольшого задания. Контрольную печать организуйте, когда рядом с принтером есть человек: сетевое управление не проверяет механику и не заменяет осмотр первого слоя.

Для этой схемы публиковать веб-интерфейс принтера напрямую через проброс его портов не требуется. Права VPN-пользователя должны давать доступ к нужной сети; доступ администратора роутера для повседневного просмотра принтера не нужен.

## Для опытных

На Keenetic SSTP может проходить через облачный KeenDNS и при частных адресах на обеих сторонах. В таком случае соединение зависит от доступности и скорости облака. Само наличие DDNS у произвольного роутера не создаёт доступ через NAT провайдера. Сверяйте режим и возможности своей модели по [руководству сервера](https://support.keenetic.ua/start/kn-1112/en/19090-sstp-vpn-server.html).

Сначала проверьте доступ по IP, затем автоматический поиск принтера. Если VPN установлен, но открывается только роутер, проверьте выбранный сегмент, маршруты и межсетевой экран. Keenetic отдельно описывает [маршрутизацию через VPN](https://support.keenetic.ua/start/kn-1112/en/21241-routing-networks-over-vpn.html); обнаружение ресурсов по сетевым именам не равнозначно доступности по адресу.

Если после подключения VPN пропал обычный интернет компьютера, проверьте использование удалённого шлюза. Инструкция Windows описывает раздельную маршрутизацию, когда туннель нужен только для домашней сети. Не отключайте межсетевой экран целиком ради проверки принтера.

VPN не исправляет отказ камеры или кнопок, уже наблюдаемый дома. Для такого симптома см. [восстановление веб-интерфейса CC1](../web-interface-recovery.md). Возможности облака Matrix для других конфигураций здесь не проверялись.

## Проверка результата

При подключённом домашнем VPN из другой сети открывается локальный адрес CC1, обновляется состояние и передаётся задание. Запишите отдельно результат видео, отправки файла и печати: успех одной функции не подтверждает остальные.

**Граница проверки:** успешную работу через SSTP подтвердил один владелец; сам вопрос независимо задавали несколько человек. Собственная настройка роутера и испытание принтера при подготовке статьи не проводились.
