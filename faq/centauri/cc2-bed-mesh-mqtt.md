# CC2: как посмотреть карту высот через MQTT

Если способом для CC1 не удалось получить карту CC2, есть сторонний вариант — **cc2-bed-mesh-sniffer**. Он записывает телеметрию во время автовыравнивания, затем строит предполагаемую сетку по координатам головы. Это помогает посмотреть данные, но не заменяет проверку первого слоя.

**Область:** CC2 с доступным локальным MQTT; версии прошивки в отчёте автора не указаны. Проверены документация и исходники проекта на 05.11.2026, без подключения к принтеру. На CC1, COSMOS и другие программы этот порядок не переносится. **Обновлено:** 05.11.2026.

## Для новичков

Способ требует Python и установки библиотек. Если с этим не работали, сначала прочитайте [инструкцию автора](https://github.com/Sixth49/cc2-bed-mesh-sniffer/tree/d92585be755f31a016634320fcfd4f3c63063bea). Для диагностики плохого первого слоя сама карта необязательна: начните с [поверхности](../first-layer-adhesion.md) и [Z-offset](first-layer-z-offset.md).

1. Проверьте [локальное подключение CC2](cc2-lan-connection.md): компьютер и принтер в одной сети, включён LAN Only, известны текущий IP и код доступа, если защита включена.
2. Возьмите из репозитория автора два файла: `cc2_mesh_sniffer.py` и `cc2_bed_mesh_3d.py`. Подготовьте Python и зависимости по его README. Инструкция относится к этому проекту, а не к любому ZIP с похожим названием.
3. Запустите первый скрипт с адресом принтера и своим кодом LAN по инструкции автора. Затем запустите штатное автовыравнивание с экрана принтера и дождитесь его завершения. После этого остановите скрипт через `Ctrl+C`. Нужный результат этого этапа — файл `cc2_raw_dump.jsonl`; автоматически найденная картинка ещё не обязательна.
4. Передайте полученный лог второму скрипту — `cc2_bed_mesh_3d.py`. По документации он создаёт таблицу `mesh_grid.csv`, изображение `mesh_heatmap.png` и интерактивный график `mesh_3d_interactive.html`.
5. Проверьте полноту сетки и повторите измерение в тех же условиях. Если точек мало или большой пик при повторе перескакивает в другое место, сначала проверяйте запись и разбор данных. По одному такому графику не подкладывайте скотч и не гните стол.

Сырой MQTT-лог и код доступа оставьте у себя. Для обсуждения обычно достаточно обезличенного графика, модели, версии прошивки и описания условий калибровки.

## Для опытных

В [просмотренном исходнике сниффера](https://github.com/Sixth49/cc2-bed-mesh-sniffer/blob/d92585be755f31a016634320fcfd4f3c63063bea/cc2_mesh_sniffer.py) клиент подписывается на MQTT-сообщения и пишет локальный лог. Запуск калибровки остаётся отдельным действием на принтере; команду смены конфигурации этот скрипт не отправляет.

[Второй скрипт](https://github.com/Sixth49/cc2-bed-mesh-sniffer/blob/d92585be755f31a016634320fcfd4f3c63063bea/cc2_bed_mesh_3d.py) восстанавливает координаты, группирует посещения точек и выбирает наиболее похожий на сетку этап. Для отбора касаний он использует порог по Z. Это эвристика, а не прямой экспорт сетки, которую прошивка применяет при печати. Исходник допускает неполную сетку, поэтому наличие CSV само по себе не подтверждает полный захват.

Интерактивный HTML загружает Plotly с внешнего CDN. Полная работа графика без интернета здесь не проверена.

## Проверка результата

Получена сетка ожидаемого размера, а повторный захват в тех же условиях даёт сопоставимые данные. Качество первого слоя проверьте отдельно. Изменение графика после вращения винтов ещё не означает, что печать исправлена.

<details data-pagefind-ignore>
<summary>Что удалось участникам чата</summary>

Один владелец CC2 не смог воспользоваться прежним способом просмотра карты. Другой сообщил о таком же затруднении и дал ссылку на собственный MQTT-инструмент. В репозитории автора опубликованы тепловая карта и 3D-график; они просмотрены вместе с кодом. Версия прошивки, сырой контрольный лог и сравнение с измерительным прибором не представлены.

В более ранней апрельской истории другой владелец скачал сохранённый файл калибровки и показал карту в отдельном визуализаторе. Это чтение готовой сетки, а не восстановление по MQTT. Версия прошивки неизвестна; тот результат не подтверждает доступность прежнего способа на других версиях. [История просмотра сохранённой карты](../../docs/evidence-history.md#cc2-saved-mesh-april).

Позднее другие владельцы получали графики в отдельной бета-программе из чата. Её автор признал ложные пики ошибкой. Связь той программы с этим репозиторием не установлена; её результаты не считаются независимыми испытаниями cc2-bed-mesh-sniffer. [Истории и границы CC2-MESH-TOOLS](../../docs/evidence-history.md#cc2-mesh-tools).
