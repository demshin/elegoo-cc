# Уведомления о печати в Telegram через Home Assistant

Чтобы узнать об окончании печати, можно связать состояние принтера в Home Assistant с Telegram-ботом. Участник чата показал сообщения с ходом печати, снимками и её завершением. Постоянно держать открытым слайсер для такого уведомления не нужно.

**Область:** Centauri Carbon, подключённый к работающему серверу Home Assistant. Исторический результат относится к декабрю 2025 года; версии HA, прошивки и интеграции не названы. Ниже использована документация, проверенная 05.11.2026. Совместимость CC2 проверяйте отдельно. **Обновлено:** 05.11.2026.

## Для новичков

1. **Сначала получите состояние принтера в HA.** Выберите интеграцию с поддержкой своей модели, например [Elegoo Printers](https://github.com/danielcherubini/elegoo-homeassistant/blob/7214c37a498dee9a94bc9194128babc6994349dc/README.md), и настройте её по инструкции автора. Проверьте, меняется ли состояние при начале и завершении задания. Одного мобильного приложения HA без работающего сервера недостаточно.
2. **Создайте своего Telegram-бота.** В [официальной инструкции HA](https://www.home-assistant.io/integrations/telegram_bot/) описаны создание через BotFather, получение токена и первое сообщение боту. Токен вводите в своей установке HA; в обсуждение и скриншоты настроек его не включайте.
3. **Добавьте интеграцию Telegram bot.** Она находится в разделе устройств и служб HA. Если нужны только исходящие уведомления, предусмотрен режим Broadcast. Добавьте свой chat ID в разрешённые получатели по инструкции. Это ваш бот и ваш чат; готового общего бота из переписки не требуется.
4. **Проверьте отправку текста отдельно.** Используйте действие `telegram_bot.send_message` для своего разрешённого чата. Пока тест не приходит, проверяйте настройку бота и получателя, а не прошивку принтера.
5. **Создайте автоматизацию по изменению состояния.** В триггере [State changed](https://www.home-assistant.io/triggers/state/) выберите сущность состояния принтера и нужный переход. Значения возьмите из своей интеграции: универсального имени сущности и состояния «готово» для всех версий здесь нет. Действием добавьте отправку сообщения.
6. **Проверьте короткое задание и отмену отдельно.** Сообщение об успешном завершении должно приходить после завершения, а не после любого выхода из печати. Если интеграция не различает эти исходы, пишите об остановке задания. Снимки добавляйте после проверки обычного текста.

## Для опытных

У HA есть и другие способы связи с Telegram. Broadcast отправляет сообщения, Polling поддерживает входящие команды; оба не требуют открывать HA для входящих соединений из интернета. Webhooks требует отдельного внешнего доступа. Выбирайте способ по задаче, не смешивая их настройки.

Интеграция Elegoo в проверенном README поддерживает Centauri Carbon и отдельно описывает локальное подключение CC2 с LAN Only. Это текущая документация проекта, а не установленная версия автора старого скриншота. Готовый blueprint для мобильных уведомлений не следует автоматически считать настроенным Telegram-ботом.

Если уведомление не пришло, проверьте три участка: изменение состояния принтера, запуск автоматизации и отправку боту. Трасса автоматизации помогает увидеть, сработал ли триггер. Полученное сообщение подтверждает доставку состояния, но не качество готовой детали.

## Проверка результата

Тестовый текст доходит до нужного чата. После короткой печати приходит одно ожидаемое уведомление, отмена не выдаётся за успешное завершение. Название задания и время помогают отличить новое сообщение от старого.
