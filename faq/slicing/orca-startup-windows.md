# OrcaSlicer не запускается в Windows: Bad Image и ошибка DLL

Если OrcaSlicer не открывается и показывает **Bad Image**, сохраните текст ошибки и попробуйте повторный запуск. В чате запуск восстанавливался после перезапуска или повторной установки Orca, но общую причину этих сбоев не установили.

**Область:** OrcaSlicer в Windows 11; ошибка запуска программы до подключения к принтеру. Номер версии в исходных случаях указан неточно или не указан. **Обновлено:** 05.11.2026.

## Для новичков

1. Запишите имя DLL и код ошибки. В одном случае на экране были `TKSTEPBase.dll`, **Bad Image** и `0xc0e90002`; отдельно Windows сообщала о блокировке `TKHLR.dll`. Другой текст ошибки может требовать другой диагностики.
2. Попробуйте запустить Orca повторно. Если открылось окно, сохраните проект и свои профили. Повторяющийся сбой после временного успеха всё ещё требует разбора.
3. Перед переустановкой сохраните копию настроек. Для обычной установки Windows [документация Orca](https://github.com/OrcaSlicer/OrcaSlicer/wiki/user_profiles#storage-location) указывает папку `%APPDATA%\OrcaSlicer`. Не удаляйте её ради повторной установки.
4. Скачайте установщик по [официальной инструкции OrcaSlicer](https://github.com/OrcaSlicer/OrcaSlicer#how-to-install), выбрав вариант под свой процессор. Одному участнику помогла установка поверх той же версии. Это проверенный им обход, а не гарантия устранения любой ошибки DLL.
5. Если Windows явно блокирует приложение через **Smart App Control («Интеллектуальное управление приложениями»)**, в руководстве Orca есть ссылка на подписанный пакет Microsoft Store. При сохраняющемся отказе передайте разработчикам версию Orca, сборку Windows, текст ошибки и способ установки. Если программа иногда открывается и в вашей сборке есть **Help → Troubleshoot Center («Помощь → Экран отладки»)**, используйте [этот раздел для сбора сведений](https://github.com/OrcaSlicer/OrcaSlicer/wiki/troubleshoot_center).

## Для опытных

Не путайте блокировку **Smart App Control** с любым сбоем антивируса или повреждением DLL. [Microsoft описывает](https://support.microsoft.com/en-us/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions) отдельную проверку доверия и подписи. По двум снимкам из чата нельзя установить, что именно повредило или заблокировало файлы.

В официальной инструкции Orca также перечислены необходимые среды выполнения. Если ваша ошибка указывает на них, используйте ссылки из этого руководства. Подмена отдельной DLL из случайного источника не повторяет подтверждённую переустановку программы.

Переход на Windows 10, отключение обновлений и защиты обсуждались как предположения; подтверждённого исправления этими действиями в выбранных случаях нет.

## Проверка результата

Orca открывается повторно, загружает сохранённый проект и выполняет нарезку без прежней ошибки. Восстановленный запуск ещё не проверяет сетевое соединение и печать на принтере.

Один владелец на новом ноутбуке с Windows 11 получал ошибку непостоянно. После установки Orca поверх прежней версии программа запустилась. Скриншоты ошибки и уведомления Windows просмотрены; долговременное устранение и причина не подтверждены.

Другой участник независимо сообщил о похожих отказах в Windows 11 и восстановлении после перезапуска. Он не уточнил, перезапускал программу или весь компьютер, а версию Orca назвал неуверенно. Это два отчёта о восстановлении запуска, без доказательства общего дефекта Windows или конкретного обновления. [Случаи ORCA-STARTUP](../../docs/evidence-history.md#orca-startup).
