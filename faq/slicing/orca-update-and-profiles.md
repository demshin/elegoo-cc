# OrcaSlicer: как обновить программу и сохранить профили

Если Орка не предлагает обновление или перестала открывать тест калибровки, можно установить новую версию вручную. Сначала сохраните свои профили принтера, пластика и процесса печати.

**Область:** настольный OrcaSlicer. Обновление слайсера и прошивка принтера выполняются отдельно. **Обновлено:** 05.11.2026.

## Для новичков

1. Запишите версию Орки и точный текст ошибки. Текущую работу сохраните через `File → Save Project` в проект 3MF. Он содержит модели и настройки этого проекта, но не заменяет копию всех ваших профилей.
2. Экспортируйте пользовательские профили через `Export Preset Bundle`. Пакет `Printer config bundle` содержит профиль принтера и связанные с ним профили пластика и процесса. Если принтеров несколько, проверьте, что сохранили нужные настройки каждого. В разных версиях названия и форматы экспорта могут отличаться; варианты описаны в [документации OrcaSlicer](https://github.com/OrcaSlicer/OrcaSlicer/wiki/import_export#presets).
3. Откройте `Help → Show Configuration Folder`, закройте Орку и скопируйте эту папку в отдельное место. При переустановке не удаляйте исходную папку конфигурации. На macOS программа удаления может предложить стереть её вместе с приложением: такое подтверждение удалит и пользовательские профили. [Где хранятся настройки](https://github.com/OrcaSlicer/OrcaSlicer/wiki/user_profiles).
4. Скачайте установочный пакет из [официальных релизов OrcaSlicer](https://github.com/OrcaSlicer/OrcaSlicer/releases). Для обычной работы разработчики рекомендуют стабильную версию. Выберите пакет для своей ОС и процессора, затем установите его по [инструкции проекта](https://github.com/OrcaSlicer/OrcaSlicer#how-to-install). Ждать уведомления внутри программы необязательно.
5. После запуска проверьте версию, свои профили и сохранённый проект. Если требуется восстановить экспортированный пакет, используйте `File → Import → Preset Configs`. Пока не убедились, что всё на месте, резервную копию оставьте.
6. Повторите действие, которое не работало: например, откройте тот же тест калибровки. Если ошибка осталась, сохраните её текст и сведения о версии для обращения в [Issues OrcaSlicer](https://github.com/OrcaSlicer/OrcaSlicer/issues). Для ошибки запуска Windows с упоминанием DLL есть [отдельный разбор](orca-startup-windows.md).

## Для опытных

Обычная переустановка сохраняет конфигурацию, согласно документации OrcaSlicer. Резервная копия нужна на случай удаления папки или проблем при переходе между версиями. Типичные пути:

| Установка | Папка конфигурации |
| --- | --- |
| Windows | `%APPDATA%\OrcaSlicer` |
| macOS | `~/Library/Application Support/OrcaSlicer` |
| Linux, AppImage или обычная установка | `~/.config/OrcaSlicer` |
| Linux, Flatpak | `~/.var/app/com.orcaslicer.OrcaSlicer/config/OrcaSlicer` |

Сначала проверьте фактическую папку через меню программы. Если после обновления профили пропали из списка, проверьте также вход в облачную учётную запись: от него зависит активная папка пользовательских профилей. [Хранение и перенос профилей](https://github.com/OrcaSlicer/OrcaSlicer/wiki/user_profiles).

## Проверка результата

Нужные профили доступны, проект открывается, прежнее действие выполняется без ошибки. Если теперь загружается тест калибровки, это подтверждает исправление работы слайсера. Качество печати и связь с принтером проверяются отдельно.

<details data-pagefind-ignore>
<summary>Что помогло участникам чата</summary>

У одного владельца OrcaSlicer 2.3.1 перестал загружать модель для теста, который он назвал калибровкой скорости потока: появлялись сообщения «Файл не содержит никаких геометрических данных» и «Не удалось загрузить файл модели». Остальные калибровки открывались. После обновления до сборки, названной 2.3.2, тест заработал. Точный канал сборки неизвестен; другой участник сообщил, что у него тест работает и в 2.3.1.

Другой владелец не получал уведомление о новой версии. После ручной установки он подтвердил, что проверка обновлений снова работает. Это два разных результата в программе, а не повтор одного и того же дефекта. Они поддерживают способ ручного обновления, но не обещают исправления любой ошибки. Номер 2.3.2 приведён как часть истории, а не рекомендация устанавливать эту старую версию. [Вопросы и результаты](../../docs/evidence-history.md#orca-manual-update).

</details>
